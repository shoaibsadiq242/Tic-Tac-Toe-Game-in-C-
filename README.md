# Tic-Tac-Toe Game in C++

A simple console-based Tic-Tac-Toe game in C++ for two players. Players take turns to place X and O on a 3×3 board, and the game detects wins, draws, and allows replaying.

## Features

- Two-player game (X and O)
- 3×3 board displayed in console
- Validates moves to prevent overwriting
- Detects wins and draws
- Option to play again
